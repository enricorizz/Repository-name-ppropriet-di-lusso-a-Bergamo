# Rizzetti Immobiliare Agent

Esperienza digitale in italiano per la promozione di proprietà di lusso a Bergamo, progettata con approccio mobile-first e ottimizzata anche per iPhone.

## Contenuto della repository

- `index.html` — landing page principale con sezione hero, proprietà in evidenza, servizi e richiesta consulenza
- `styles.css` — stile mobile-first con attenzione a leggibilità, tap target e layout iPhone-friendly
- `script.js` — logica client-side per raccomandazioni rapide e rendering delle proprietà

## Avvio rapido

Apri direttamente `index.html` in un browser moderno.

Se preferisci un server locale:

```bash
python3 -m http.server 4173
```

Poi visita `http://localhost:4173`.

## Obiettivi raggiunti

- interfaccia completamente in italiano
- esperienza mobile-first adatta a Safari su iPhone
- presentazione premium per immobili di lusso
- richiesta guidata per ricevere una selezione iniziale di proprietà

## Note

Il progetto è statico e non richiede dipendenze esterne per funzionare.
