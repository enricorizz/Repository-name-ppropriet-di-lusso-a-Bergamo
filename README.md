# Rizzetti Immobiliare Agent

> Agente IA per la vendita di proprietà di lusso a Bergamo — v2.0.0

Sito web mobile-first in italiano per la presentazione e promozione di proprietà di lusso a Bergamo, con contatti diretti integrati e interfaccia ottimizzata per smartphone.

---

## Installazione rapida

```bash
git clone https://github.com/enricorizz/Repository-name-ppropriet-di-lusso-a-Bergamo.git
cd Repository-name-ppropriet-di-lusso-a-Bergamo
```

Apri `index.html` direttamente nel browser, oppure avvia un server locale:

```bash
npm start
# oppure
python3 -m http.server 4173
```

Poi visita: [http://localhost:4173](http://localhost:4173)

---

## Struttura del progetto

| File | Descrizione |
|------|-------------|
| `index.html` | Landing page principale con hero, proprietà e contatti |
| `styles.css` | Stile mobile-first ottimizzato per iPhone e Safari |
| `script.js` | Logica client-side: raccomandazioni, rendering proprietà, contatti precompilati |
| `package.json` | Metadati progetto e script di validazione |
